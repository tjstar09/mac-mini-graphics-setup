02. Step-by-Step Assembly & Windows Provisioning

Detailed engineering protocol detailing mechanical seating, electrical safety interlocks, Mac Mini bus topology, and clean Boot Camp bare-metal provisioning.

PHASE A

Physical Hardware Assembly

Benchtop ESD Safe Protocol
  1. 1 Dock Foundation & Standoff Installation Step 1.1

    Place the TH3P4G3 dock on an antistatic mat. Fasten the included metallic mounting brackets onto the base PCB. If using an ATX power supply, install the taller ATX mounting plate; if using an SFX PSU, screw in the compact SFX bracket. Ensure rubber anti-vibration footpads are seated beneath the dock frame to prevent short circuits.

  2. 2 GPU PCIe Socket Seating & Anti-Sag Retention Step 1.2

    Unlock the PCIe x16 retention latch at the tail of the slot. Gently insert the RTX 4060 Ti 16GB dual-slot card perpendicularly until you hear a decisive mechanical click. Fasten the two screws through the card's metal I/O bracket into the dock pillar. Warning: Never leave the card cantilevered without securing the bracket, as card flex under thermal cycling damages the gold PCIe traces.

  3. 3 Power Distribution & Wire Harnessing Step 1.3

    Connect the main 24-Pin ATX power harness from your 550W PSU directly to the 24-Pin socket on the TH3P4G3 dock. Next, route a dedicated 8-pin (6+2) PCIe power cable directly from the PSU to the RTX 4060 Ti 16GB top connector. Ensure the clip clicks securely into place. Connect the dock's 4-Pin / 8-Pin CPU auxiliary power header if your dock model specifies it for active 85W PD reverse charging.

  4. 4 Mac Mini Thunderbolt 3 Bus Topology Allocation Crucial Architecture Step

    The 2018 Mac Mini features 4 physical Thunderbolt 3 ports powered by two distinct Intel Alpine Ridge TB3 host controllers:

    BUS 0 (Controller 1):
    Ports 1 & 2 (Closest to HDMI port)
    Recommended: Dedicate exclusively to eGPU!
    BUS 1 (Controller 2):
    Ports 3 & 4 (Closest to Power / 10GbE)
    Reserve for USB-C SSDs, Webcams & Hubs

    ⚠️ Do NOT plug any other high-bandwidth USB-C or Thunderbolt device into the port adjacent to the eGPU on the same bus. Sharing the controller divides the PCIe Gen3 x4 32Gbps lanes, causing frame drops and PCIe buffer overruns.

  5. 5 Standby Power State Verification Step 1.5

    Switch the PSU rocker to '1' (ON). Observe the small standby LED on the TH3P4G3 dock illuminated in amber or faint green. The GPU fans should remain stationary (0dB mode). CRITICAL SAFETY RULE: Do NOT plug the Thunderbolt cable into the Mac Mini yet! Leave it completely unplugged during Windows Boot Camp provisioning in Phase B.

PHASE B

Windows Installation via Boot Camp Assistant

Bare-Metal 100% Speed Setup
  1. 1 T2 Security Chip & SIP Configuration in macOS macOS Recovery

    Reboot the Mac Mini while holding Command + R to enter macOS Recovery. In the top menu bar, select Utilities > Startup Security Utility. Authenticate as Administrator and configure:

    Secure Boot: Medium Security (or No Security)
    Allowed Boot Media: Allow booting from external media

    This enables subsequent chainloading of custom EFI loaders (rEFInd / automated-eGPU) required to bypass Error 12.

  2. 2 Boot Camp Assistant Partitioning (1.2TB - 1.5TB on 2TB NVMe) macOS Desktop

    Boot into normal macOS. Download the official 64-bit Windows 10/11 ISO from Microsoft. Launch Boot Camp Assistant from Applications > Utilities. Select your ISO image. In the partition slider, allocate 1,200 GB to 1,500 GB for Windows to ensure ample high-speed NVMe headroom for Steam 4K game installs (100GB+ each), local LLM model weights (Ollama GGUF cache), and PyTorch checkpoints.

  3. 3 The Zero-eGPU Installation Rule MANDATORY ISOLATION

    🛑 DO NOT CONNECT THE THUNDERBOLT eGPU DURING WINDOWS SETUP!

    Connect your 4K TV or temporary monitor directly to the Mac Mini's built-in HDMI 2.0 port. Allow the Mac Mini to restart into the Windows setup wizard. Complete Windows installation using the native Intel UHD 630 iGPU. If an external eGPU is connected at this juncture, the Windows ACPI installer allocates memory maps incorrectly, leading to kernel trap BSODs (INACCESSIBLE_BOOT_DEVICE or SYSTEM_THREAD_EXCEPTION_NOT_HANDLED).

  4. 4 Apple Windows Support Software Deployment Windows First Boot

    Upon reaching the Windows desktop, the Apple Boot Camp installer will automatically prompt you. Execute D:\WindowsSupport\BootCamp\setup.exe. This provisions proper Apple T2 drivers, Intel Chipset drivers, Bluetooth 5.0, Wi-Fi, and audio controller. Restart Windows once complete. Run Windows Update to grab all critical platform patches, then restart again.

03. Bypassing the Boot Camp "Error 12" Resource Crisis

Deep technical breakdown of Apple EFI DSDT table allocation vs Windows PCI root bridge address exhaustion, and the turnkey automated EFI bypass procedure.

⚠️ Technical Root Cause Analysis: Windows Code 12 on Mac Mini

When Windows boots on an Intel Mac Mini via Apple's Boot Camp EFI subsystem, Apple's firmware presents an ACPI Differentiated System Description Table (DSDT) configured with a constrained 32-bit Memory-Mapped I/O (MMIO) window under the primary PCI Root Bus (PCI0._CRS).

While macOS natively uses 64-bit BAR address space for hot-plugged devices, Windows 10/11 strictly obeys the Apple DSDT's declared 32-bit ceiling (approximately 2.5GB reserved window). The NVIDIA RTX 4060 Ti requires massive contiguous Base Address Register (BAR) allocations to expose its 16GB VRAM and PCIe translation registers. Because the remaining 32-bit MMIO space is already congested by the Intel UHD 630, T2 controller, and NVMe SSD, Windows Device Manager flags the card with:

"This device cannot find enough free resources that it can use. If you want to use this device, you will need to disable one of the other devices on this system. (Code 12)"

🛠️ The Verified EFI Memory Bridge Bypass Protocol

Zero Soldering · Pure EFI Injection
1 Step 1: Install automated-eGPU EFI Boot Manager (or rEFInd with apple_set_os.efi)

The automated-eGPU EFI loader acts as a pre-boot shim. It intercepts the boot process before Windows' bootmgfw.efi or winload.efi executes, and patches the ACPI table in system RAM to inject a 64-bit QWordMemory aperture into PCI0._CRS, expanding MMIO space to 64GB.

macOS Terminal Command (In Recovery or SIP-disabled macOS): 
curl -s https://raw.githubusercontent.com/mayankk2308/automate-eGPU/master/automate-eGPU.sh -o automate-eGPU.sh
chmod +x automate-eGPU.sh
./automate-eGPU.sh --efi

Alternative Standalone Method: Use rEFInd installed to the EFI System Partition (ESP) configured to execute apple_set_os.efi. This tricks the Mac firmware into identifying the OS as macOS, instructing Apple's SMC and firmware to enable full 64-bit PCI MMIO aperture.

2 Step 2: Windows BCD & Dynamic Tick Tweaks

In Windows, open Command Prompt as Administrator and run the following BCD commands to disable legacy PCIe forced interrupt constraints and prevent power-state resets over the Thunderbolt bus:

Windows Administrator CMD: 
bcdedit /set pciexpress forcedisable
bcdedit /set disabledynamictick yes
bcdedit /set useplatformclock true
3 Step 3: The Cold-Boot Connection Dance (Exact Power Sequence)

To guarantee that Windows enumerates the RTX 4060 Ti without bus arbitration failure, execute this exact power-up cadence:

1. Power ON the eGPU ATX Power Supply (dock in standby, LED lit).
2. Plug the certified TB3/TB4 cable into Mac Mini Bus 0 Port 1 (leftmost port next to HDMI).
3. Turn ON the Mac Mini. The TH3P4G3 dock will immediately detect the TB3 signal, trigger the 24-pin ATX relay, and power up the RTX 4060 Ti.
4. Select the EFI Boot / automated-eGPU entry (or rEFInd) in the Mac boot picker.
5. Windows boots into desktop. Device Manager will list NVIDIA GeForce RTX 4060 Ti under Display Adapters with "This device is working properly"!
4 Step 4: Clean NVIDIA Desktop Driver Installation

Download the latest NVIDIA Desktop Game Ready or Studio Driver (Version 555+ or 560+) directly from nvidia.com. During setup, select Custom (Advanced) > Check "Perform a clean installation". Do NOT install GeForce Experience if you desire zero background telemetry overhead.

05. Troubleshooting & Maintenance Matrix

Interactive diagnostic grid addressing display drops, PCIe disconnects, driver conflicts, CUDA memory limits, and HDMI soundbar routing.

Root Cause Diagnosis:

At 4K 120Hz with 10-bit HDR, HDMI bandwidth demand reaches 40.1 Gbps. Cheap or uncertified cables fail to sustain FRL (Fixed Rate Link) signaling, causing the TV display engine to lose clock sync and drop to a black screen for 2–4 seconds before renegotiating.

Prescribed Engineering Remedy:
  1. Replace HDMI cable with an official Ultra High Speed 48Gbps Certified cable (max 2 meters).
  2. Ensure the TV port has Enhanced Format / HDMI Deep Color toggled ON in TV settings.
  3. In NVIDIA Control Panel, if 120Hz flickers, switch color format from RGB to YCbCr 4:2:2 or YCbCr 4:2:0 to reduce bandwidth overhead.
Root Cause Diagnosis:

Windows default Power Plan enables PCI Express Link State Power Management (ASPM), which commands the Thunderbolt PCIe bridge to enter low-power sleep states (L0s/L1) during microsecond idle pauses. When sudden GPU load spikes occur, waking the link triggers a PCIe timeout fault, resetting the controller.

Prescribed Engineering Remedy:
  1. Open Power Options > Change plan settings > Change advanced power settings.
  2. Expand PCI Express > Link State Power Management. Set to OFF.
  3. In Device Manager > Universal Serial Bus controllers > Intel USB 3.1 / Thunderbolt controllers > Properties > Power Management: Uncheck "Allow the computer to turn off this device to save power".
  4. Ensure TB3 cable is strictly ≤0.8m and connected to Bus 0 (Port 1).

Major Windows updates occasionally overwrite custom BCD parameters or replace clean desktop drivers with generic WHQL versions from Windows Update.

Permanent Mitigation Procedure:
  1. Re-run bcdedit /set pciexpress forcedisable in Administrator CMD.
  2. Download Display Driver Uninstaller (DDU), reboot Windows into Safe Mode, and run "Clean and do NOT restart".
  3. Reinstall the official NVIDIA Desktop driver with "Clean installation" checked.
  4. Disable automatic driver updates in Windows: Press Win + R, type sysdm.cpl > Hardware > Device Installation Settings > Select "No (your device might not work as expected)".
PyTorch Memory Defragmentation:

Set the Windows system environment variable PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True. This forces PyTorch to use dynamic memory segments rather than throwing an OOM when encountering virtual address fragmentation.

Ollama Context Optimization:

In Ollama, if running 16k or 32k context with Llama 3, restrict num_ctx 16384 in your Modelfile to maintain 4GB headroom for KV-cache without overflowing into system RAM over PCIe.

The Mac Mini features an internal low-fidelity mono speaker driven by Apple's Cirrus Logic audio controller. When gaming or streaming media on a 4K TV, audio must be piped through the RTX 4060 Ti HDMI audio controller.

Resolution Steps:
  1. Verify NVIDIA High Definition Audio driver is installed (bundled with the GeForce graphics package).
  2. Click the Windows speaker icon in taskbar > Click the device selector arrow > Choose your TV Name (NVIDIA High Definition Audio) as the default playback device.
  3. In Windows Sound settings > More sound settings > Right-click TV > Configure Speakers > Select 5.1 Surround or Stereo.
  4. If using an eARC Soundbar connected to the TV, ensure TV digital audio output format is set to Pass-Through or Bitstream to preserve lossless Dolby Atmos / DTS audio.
